# PilotOps Docs

Este repositorio contiene la documentación técnica oficial de PilotOps Platform.

La documentación forma parte del producto y debe mantenerse actualizada junto con el código fuente.

## Documentos

- `00_Glosario.md`: definiciones comunes utilizadas en la plataforma.
- `01_Arquitectura.md`: arquitectura general de PilotOps Platform.
- `02_Estandares.md`: reglas de trabajo, desarrollo y documentación.
- `03_Modelo_Datos.md`: modelos comunes y equivalencias entre plataformas.
- `04_Scraping.md`: integración con Operaciones Portuarias.
- `05_Backend_Oracle.md`: responsabilidades del backend.
- `06_Notificaciones.md`: estrategia de notificaciones push.
- `07_Roadmap.md`: evolución prevista del proyecto.
- `08_Changelog.md`: historial funcional de cambios.

## Principio general

Cada tema debe documentarse en un único lugar.

La documentación debe explicar las decisiones, no solamente describir archivos o código.
